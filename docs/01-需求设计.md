# 需求设计

## 1. 项目概述

MiniCPM 全科 Coach 是一个面向中文中小学生的全模态学科学习工具。它复用 `OpenBMB/MiniCPM-o-Demo` 的图片、音频和文本理解能力，将一道题组织成可确认、可追问、可分步验证的教学过程；并参考 `ai-teaching-video-platform` 增加了登录鉴权与管理员用户管理。

系统首期覆盖语文、数学、英语、物理、化学、政治、历史、地理、生物九个学科。学科由统一 `subject` 字段传递；数学使用已有的确定性规则化 Mock 解析，其他学科提供通用的学科化提示、步骤和练习占位，真实模式由 MiniCPM-o 按学科专属提示词完成。

首版采用 Turn-based Chat（按轮次对话），不承诺实时全双工课堂。无 GPU 或模型 `base_url` 为空时，系统必须以明确的 Mock 演示模式运行。

## 2. 用户与场景

| 用户 | 主要目标 | 典型场景 |
| --- | --- | --- |
| 初中学生 | 登录后看懂题目并掌握解法，而非只拿答案 | 拍照上传作业，先看懂题目并尝试一步，再总结方法 |
| 教师 | 登录后体验教学流程，或辅导学生使用 | 使用示例题检查提示护栏和完整解析 |
| 管理员 | 管理账号与查看系统统计 | 登录后台调整用户角色/状态，查看用户规模 |
| 开发/评测人员 | 验证全模态链路、鉴权和教学护栏 | Mock 运行、鉴权回归、固定 30 题评测、接入 GPU vLLM-Omni |

## 3. 产品目标

### 3.1 MVP 目标

1. 支持账号登录、学生/教师公开注册、管理员种子账号初始化。
2. 教学接口默认要求登录；未登录时前端进入登录页。
3. 支持 PNG、JPEG、WebP、PDF 题目文件上传、浏览器摄像头实时拍题和直接输入题面；PDF 在浏览器内预览，识别时转换首页为图片。
4. 识别后展示可编辑题面，用户确认后才能开始讲解。
5. 默认输出苏格拉底式提示，避免在提示阶段直接给最终答案。
6. 支持文字追问和浏览器录音追问；音频按 16 kHz PCM Float32 发送。
7. 讲解文本可增量显示；学生先完成一次文字或语音尝试，再进入方法总结，结束后显示步骤、答案和可选 TTS，播放中的语音回答可被学生打断。
8. 支持浏览器本地保存和恢复最近学习记录，不保存原始图片。
9. 管理员可查看统计并管理用户角色/状态。
10. 提供 Docker Compose 交付和固定 30 题 Mock 评测。
11. 前端采用 React + Vite 深色侧栏工作台，支持登录门禁与管理员后台。
12. 提供比赛体验账号一键重置、真实模型评测脚本、HTTPS Nginx 模板与公网验证脚本。

### 3.2 非目标

- 首版不提供跨设备云同步、学校/班级组织树和完整教务后台。
- 首版不实现全双工实时音频/视频课堂。
- 首版不保证任意高中、竞赛或大学级题目的正确解析；不同学科的事实性答案仍应由教师或教材复核。
- 标注框依赖模型返回归一化坐标；没有坐标时只显示原图和题面。
- 首版默认 SQLite 单机账号库；生产多实例应切换 MySQL，不作为完整教务账号中心。

## 4. 功能需求

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-001 | 上传题图或输入文字题面 | P0 | 支持 PNG/JPEG/WebP/PDF，单文件不超过 8 MB，PDF 最多 20 页并提供浏览器预览；文字题面不超过 4000 字符 |
| FR-002 | 题面识别与确认 | P0 | 返回题面、置信度、可选标注和识题会话；用户可编辑，确认前不调用讲解流程；识别成功但没有完整题目时返回 `no_problems=true` 与重拍/手输提示 |
| FR-003 | 提示式教学 | P0 | `stage=hint` 返回引导问题，`final_answer` 必须为空 |
| FR-004 | 完整解析与方法总结 | P0 | 学生完成一次文字或语音尝试后可主动进入总结；`stage=explain` 返回步骤、可迁移方法归纳和 `final_answer`，步骤包含标题、正文、状态 |
| FR-005 | 文字追问 | P0 | 当前登录会话内保留最近对话，后端根据 `session_id` 关联上下文 |
| FR-006 | 语音追问 | P1 | 浏览器录音为 16 kHz Float32 PCM Base64，单段不超过 60 秒，Base64 不超过 4,000,000 字符；服务端转 WAV 后发送；模型 TTS 为 24 kHz WAV 播放 |
| FR-007 | 流式讲解 | P1 | `/api/lesson/stream` 逐段发送 `text_delta`，结束发送结构化 lesson 和 done |
| FR-008 | 图片标注 | P1 | 模型返回合法坐标时绘制标注框和标签，越界坐标被忽略 |
| FR-022 | 摄像头拍题 | P1 | 浏览器经用户授权打开摄像头，优先使用后置摄像头；服务端 Permissions-Policy 允许同源页面使用摄像头，Canvas 捕获 JPEG 后复用上传识别链路，帧数据不落盘 |
| FR-023 | 题图贯穿讲解 | P0 | 识题后原图短期保存在服务端教学会话内存；学生可先修正题面，首次确认讲解继续携带原图；原图不进入错题本、本地记录或数据库 |
| FR-024 | 真实模式降级可见 | P0 | 页面显示 Real/Mock 模式；MiniCPM-o 识题异常且没有文本回退时返回明确 502，提供 `problem_text` 时返回显式降级状态、原因并保留题图 |
| FR-025 | TTS 可打断 | P1 | 学生可停止当前语音回答；开始新录音或新讲解时自动停止旧语音，文字内容仍完整保留 |
| FR-009 | 本地记录 | P1 | 用户主动保存后写入 `localStorage`；音频和原始图片不写入记录 |
| FR-010 | Mock/真实模式 | P0 | `/api/health` 和页面模式标识一致；`config/minicpm.json` 的 `base_url` 为空时无需 GPU 也可运行 |
| FR-011 | 反馈 / 错题本 | P0 | 用户可标记“听懂/没听懂”；没听懂写入账号错题本，并推荐同类练习；不持久化原始题图 |
| FR-012 | 重新开始 | P1 | 删除服务端教学会话并清理当前浏览器课堂状态 |
| FR-013 | 登录注册 | P0 | 支持邮箱密码登录；公开注册仅 student/teacher；管理员不可公开注册 |
| FR-014 | 鉴权保护 | P0 | 默认教学 API 无有效 HttpOnly Cookie 或 Bearer Token 返回 401；禁用账号返回 401 |
| FR-015 | 管理员用户管理 | P0 | 管理员可查看用户列表、修改角色/状态；学生/教师访问管理接口返回 403 |
| FR-016 | 教学会话隔离 | P0 | 教学会话绑定创建用户；其他用户即使获得 `session_id` 也不能读取、复用或删除 |
| FR-017 | 模型服务鉴权 | P0 | 模型配置支持 API Key；生产远端必须启用 API Key，应用通过 `Authorization: Bearer` 访问 |
| FR-018 | 生产传输安全 | P0 | HTTPS 部署时设置 `MATH_COACH_COOKIE_SECURE=true`，并建议开启 HSTS |
| FR-019 | 错题重练 | P0 | 学生登录后先进入当前学习工作区，可从侧栏进入按薄弱知识点聚合的待重练题；重练时隐藏参考答案，提交最终答案后用确定性数学等价判定 |
| FR-020 | 递进提示 | P0 | 第 1 次答错提示知识点，第 2 次提示关键步骤，第 3 次展示参考答案并允许学生标记已理解；答对一次即标记掌握 |
| FR-021 | 重练历史 | P0 | 每次提交保存学生输入、正误、提示层级和时间；错题主记录汇总尝试次数、答对次数和最新状态；存量错题从第 1 次新尝试开始计数 |

## 5. 角色与权限

| 能力 | 学生 | 教师 | 管理员 |
| --- | :---: | :---: | :---: |
| 登录 / 查看 `/api/auth/me` | ✅ | ✅ | ✅ |
| 公开注册 | ✅ | ✅ | ❌ |
| 使用识题/讲解/语音教学 API | ✅ | ✅ | ✅ |
| 访问管理后台 | ❌ | ❌ | ✅ |
| 修改其他用户角色/状态 | ❌ | ❌ | ✅ |

规则：

1. 公开注册不能创建 `admin`。
2. 管理员账号通过环境变量种子化（`ADMIN_EMAIL` / `ADMIN_PASSWORD`）。
3. 教学会话 `session_id` 仍是短期内存状态，与登录 token 分离。
4. `MATH_COACH_AUTH_REQUIRED=false` 时允许匿名调用教学接口，仅用于本地开发。

## 6. 教学约束

- 先确认题面，再讲解。
- 默认先问一个可回答的小问题，避免直接公布答案。
- 任何一步都应说明使用的公式、等式性质或几何关系。
- 需要完整解析时才展示最终答案。
- 模型不确定时必须降低置信度或明确提示用户核验。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | Mock 请求应即时完成；真实模型 HTTP 连接超时 10 秒，总响应读取超时 90 秒 |
| 可用性 | vLLM-Omni 不可用时返回可读错误；前端恢复发送按钮 |
| 安全 | 图片 MIME/文件签名/尺寸校验、8 MB 与 2000 万像素限制；PDF 校验签名、页数与页面尺寸并仅渲染为图片；音频 Base64 严格校验并限制时长；CORS 禁止通配符；密码 scrypt 哈希；登录 token 仅通过 HttpOnly Cookie 暴露，服务端只保存 SHA-256 哈希且可撤销 |
| 隐私 | 原始图片只用于当前教学会话，默认 30 分钟未活动过期；本地记录只保存题面和解析，音频字段剥离 |
| 兼容性 | 桌面 Chrome/Edge 为首选；移动端采用响应式布局；录音不支持时仍可文字提问 |
| 可测试性 | 代码级测试、鉴权回归、Mock 固定题集评测、真实模型 30 题评测、HTTP/SSE 冒烟 |

## 8. 评测基线

`eval/questions.json` 固定 30 题，覆盖一元一次方程、因式分解、一次函数、平面几何和解析几何。当前 Mock 目标与结果为：提示护栏 `30/30`，可输出完整解析 `30/30`。

真实 MiniCPM-o 基线见 `eval/REAL_MODEL_EVALUATION.md`：请求错误 `0/30`，提示护栏 `30/30`；保守答案等价判定 `24/30`，人工复核 6 个格式差异后语义正确 `30/30`。完整解析 p50/p95 为 `17.60s/77.50s`，首事件 p50/p95 为 `0.88s/16.97s`；文本问答、图片识题和 TTS 探测均通过。

鉴权与安全回归：`tests/test_auth.py` 覆盖登录、注册限制、教学 API 401/200、管理员用户管理与禁用账号；`tests/test_api.py` 覆盖上传、音频、限流、安全头、会话隔离、题图贯穿、无题目空结果、显式降级、过期清理、全科学科契约和按需语音。整体 `pytest` 基线 `85 passed`。
