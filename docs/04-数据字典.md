# 数据字典

## 1. 约定

- JSON 字段使用 `snake_case`。
- 坐标为相对图片显示区域的 0 到 1 小数，不是像素。
- `null` 表示当前阶段没有值，不等同于空字符串。
- 时间字段使用 ISO 8601 字符串。

## 2. 角色与状态枚举

### 2.1 `role`

| 值 | 说明 |
| --- | --- |
| `student` | 学生，默认可公开注册 |
| `teacher` | 教师，可公开注册 |
| `admin` | 管理员，仅种子/管理员分配 |

历史值 `user` 读入时归一为 `student`。

### 2.2 `status`

| 值 | 说明 |
| --- | --- |
| `active` | 可登录 |
| `disabled` | 禁止登录与调用受保护接口 |

### 2.3 `grade`

学生可选年级：`grade1`…`grade12`，分别对应小学一年级至高中三年级。

### 2.2 `subject`

| 值 | 标签 | 教学侧重点 |
| --- | --- | --- |
| `chinese` | 语文 | 阅读理解、古诗文、写作与语言运用 |
| `math` | 数学 | 概念、推理、计算与图形关系 |
| `english` | 英语 | 词汇、语法、阅读、写作与口语表达 |
| `physics` | 物理 | 现象、模型、公式、实验与单位 |
| `chemistry` | 化学 | 物质、反应、方程式、实验与守恒 |
| `politics` | 政治 | 概念辨析、材料分析与观点论证 |
| `history` | 历史 | 时间线、因果关系、材料与史实 |
| `geography` | 地理 | 地图、区域特征、自然与人文规律 |
| `biology` | 生物 | 结构功能、生命过程、实验与证据 |

缺省学科为 `math`；未知中文标签会归一化到对应代码，未知代码回退数学。

## 3. 账号与登录对象

### 3.1 `User`（存储）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | `user_` 前缀 ID |
| `email` | string | 是 | 小写唯一邮箱 |
| `password_hash` | string | 是 | `scrypt$salt$digest` |
| `nickname` | string | 是 | 2-32 字 |
| `role` | enum | 是 | `student` / `teacher` / `admin` |
| `status` | enum | 是 | `active` / `disabled` |
| `grade_code` | string/null | 否 | 学生年级 |
| `created_at` | string | 是 | ISO 时间 |

### 3.2 `public_user`（API 返回）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 用户 ID |
| `email` | string | 邮箱 |
| `nickname` | string | 昵称 |
| `role` | enum | 角色 |
| `status` | enum | 状态 |
| `grade` | string/null | 年级 |
| `created_at` | string/null | 创建时间 |

不包含 `password_hash`。

### 3.3 `AuthSession`（存储）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 随机 URL-safe 会话 token 的 SHA-256 哈希，不保存明文 |
| `user_id` | string | 关联用户 |
| `created_at` / `updated_at` / `expires_at` | string | 创建、刷新与过期时间；默认 7 天 |

### 3.4 账号存储（SQLite / MySQL）

默认后端为 SQLite（`MATH_COACH_SQLITE_PATH`，默认 `data/math-coach.db`）；`MATH_COACH_DB_BACKEND=mysql` 时写入 MySQL。旧环境变量 `MATH_COACH_AUTH_DB` 仅用于兼容推导数据目录。核心表：`users`、`sessions`、`notebook_items`。

## 4. 鉴权请求/响应

### 4.1 `LoginRequest`

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| `email` | string | 是 |
| `password` | string | 是 |

### 4.2 `RegisterRequest`

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `email` | string | 是 | 邮箱格式 |
| `password` | string | 是 | 8-128，含字母和数字 |
| `nickname` | string | 是 | 2-32 |
| `role` | enum | 否 | 默认 `student`；仅 `student`/`teacher` |
| `grade` | string/null | 否 | 学生年级 |

### 4.3 `AuthResponse`

```json
{
  "cookie_auth": true,
  "user": { "id": "...", "email": "...", "nickname": "...", "role": "student", "status": "active", "grade": "grade8" }
}
```

会话 token 仅通过响应头 `Set-Cookie: math_coach_token=...; HttpOnly; SameSite=Lax` 下发；生产 HTTPS 部署还带 `Secure`。JSON 响应体不包含 token。

### 4.4 `AdminUserUpdateRequest`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `role` | enum/null | 否 | 目标角色 |
| `status` | enum/null | 否 | `active` / `disabled` |
| `nickname` | string/null | 否 | 新昵称 |
| `password` | string/null | 否 | 重置密码 |

### 4.5 `AdminStats`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `users_total` | number | 用户总数 |
| `users_active` | number | 活跃用户数 |
| `users_by_role` | object | `{student, teacher, admin}` 计数 |
| `sessions_total` | number | 登录会话数 |
| `mode` | string | `mock` / `minicpm` |
| `upstream_configured` | boolean | 是否配置上游 |

## 5. 教学 API 对象

### 5.1 `Annotation`

| 字段 | 类型 | 必填 | 约束 | 示例 |
| --- | --- | --- | --- | --- |
| `label` | string | 是 | 1-80 字符 | `题目区域` |
| `x` | number | 是 | `0 <= x <= 1` | `0.10` |
| `y` | number | 是 | `0 <= y <= 1` | `0.15` |
| `width` | number | 是 | `0 < width <= 1` | `0.80` |
| `height` | number | 是 | `0 < height <= 1` | `0.35` |

额外约束：`x + width <= 1` 且 `y + height <= 1`。单次最多返回 12 项。

### 5.2 `RecognizeResponse`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `subject` | string | 是 | 归一化后的学科代码 |
| `problem` | string | 是 | 默认选中题目的可编辑识别题面 |
| `problems` | RecognizedProblem[] | 是 | 图片/PDF 中识别出的候选题列表，最多 20 项 |
| `selected_problem_id` | string/null | 否 | 默认选中题目 ID，通常为第一项 |
| `confidence` | number | 是 | 0-1 置信度 |
| `source` | enum | 是 | `mock` 或 `minicpm` |
| `needs_confirmation` | boolean | 是 | 当前固定为 `true` |
| `annotations` | Annotation[] | 是 | 无标注时为空数组 |
| `session_id` | string/null | 否 | 携带题图识别时返回，用于确认后继续讲解 |
| `degraded` | boolean | 是 | 真实识题异常回退 Mock 时为 `true` |
| `degraded_reason` | string/null | 否 | 最长 300 字符，面向用户说明降级与重试策略 |
| `no_problems` | boolean | 是 | 识别成功但图片/PDF 中没有完整题目时为 `true` |
| `message` | string/null | 否 | 最长 300 字符，面向用户说明无题目后的重拍或手输策略 |

语义说明：`source=minicpm, degraded=false` 表示真实识题成功；`source=mock, degraded=true` 表示真实识题异常后显式回退；未配置真实模型时 `source=mock, degraded=false`。`no_problems=true` 是成功识别后的空结果，`problem` 为空字符串、`problems` 为空数组且不创建题图会话。

`RecognizedProblem` 包含 `id`、`problem` 和可选 `annotations`。`problem` 为清洗后的单题题面，不包含原始 JSON、页眉或其他题号。

### 5.3 `LessonRequest`

| 字段 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `session_id` | string/null | 否 | 最长 80；首次请求为空 |
| `problem` | string | 是 | 1-4000 字符 |
| `message` | string | 否 | 默认提示语，最长 2000 |
| `history` | object[] | 否 | 最多 16；服务端不信任其覆盖会话 |
| `stage` | enum | 否 | `hint`、`explain`、`practice`；默认 `hint` |
| `tts` | boolean | 否 | 默认 `false`；朗读通过独立 `/api/speech` 按需生成 |
| `audio_base64` | string/null | 否 | 最长 4,000,000 字符；严格 Base64，解码后为 Float32 PCM 且不超过 60 秒 |
| `audio_sample_rate` | integer | 否 | 8000-48000，浏览器默认 16000 |

### 5.4 `Step`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | string | 是 | 步骤标题 |
| `body` | string | 是 | 步骤解释、公式或计算 |
| `state` | enum | 是 | `active`、`done`、`locked` |

### 5.5 `LessonResponse`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `subject` | string | 是 | 归一化后的学科代码 |
| `session_id` | string | 是 | 服务端课堂会话 ID |
| `stage` | string | 是 | 本次讲解阶段：`hint`、`explain` 或 `practice` |
| `reply` | string | 是 | 当前轮教师回复 |
| `steps` | Step[] | 是 | 结构化教学步骤 |
| `final_answer` | string/null | 是 | 提示阶段为空，完整解析阶段可有值 |
| `next_question` | string | 是 | 推荐的下一步追问 |
| `confidence` | number | 是 | 0-1 |
| `source` | enum | 是 | `mock` 或 `minicpm` |
| `audio_base64` | string/null | 是 | 合并后的 24 kHz WAV Base64 |
| `audio_mime` | string/null | 是 | 例如 `audio/wav` |

### 5.6 `FeedbackRequest`

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `problem` | string | 是 | 当前题面 |
| `helpful` | boolean | 是 | 是否有帮助 |
| `note` | string | 否 | 最长 500 字符 |

## 6. 课堂会话对象 `TeachingSession`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | UUID hex 风格 ID |
| `owner_id` | string | 创建该课堂的登录用户 ID |
| `subject` | string | 当前学科代码，默认 `math` |
| `problem` | string | 会话绑定题面 |
| `history` | object[] | 最近最多 16 条 user/assistant 消息 |
| `stage` | string | 当前教学阶段，初始为 `confirm` |
| `image_bytes` | bytes/bytes[]/null | 识题后短期缓存的原图片；多页 PDF 缓存各页 PNG；仅内存，不序列化、不落库 |
| `image_mime` | string | 题图 MIME，默认 `image/png` |
| `touched_at` | datetime | UTC 最近访问时间 |

生命周期：最多 200 个会话；访问时清理超过 30 分钟未活动的会话；删除会释放题图。带图会话仅允许在 confirm 阶段更新 OCR 后的题面。

## 7. 浏览器本地存储

### 过渡期 `math_coach_token`

React 前端不再主动写入登录 token，浏览器认证使用 HttpOnly Cookie。该键仅为兼容旧的过渡期脚本保留；收到 401 时会被清理。API 测试和自动化脚本仍可直接使用 `Authorization: Bearer <token>`。

### `mathCoachSaved` / `mathCoachLessons`

本地学习记录数组（实现键名为 `mathCoachSaved`）。每项大致结构：

```json
{
  "id": "...",
  "subject": "math",
  "problem": "矩形长 6，宽 4，求面积。",
  "reply": "使用公式 ...",
  "final_answer": "24",
  "saved_at": "2026-08-06T12:00:00.000Z"
}
```

最多保留约 30 项。原始图片、录音和服务端 history 不写入。

### `mathCoachProgress`

字符串形式的非负整数，用于显示今日完成题数。页面展示时最多显示 `3`。

### 运行时内存状态

- `cameraStreamRef`：当前摄像头 `MediaStream`；关闭、拍摄完成、组件卸载、切换题目或重置时释放。
- `audioRef`：当前 TTS `HTMLAudioElement`；打断、新请求或播放结束时清理。
- `sessionId`：当前服务端教学会话；确认前移除图片会删除会话并清空，确认后保留用于多轮讲解。

## 8. SSE 事件对象

| `type` | 字段 | 说明 |
| --- | --- | --- |
| `session` | `session_id` | 当前课堂会话 ID |
| `text_delta` | `text_delta` | 一段增量文本 |
| `lesson` | `lesson` | 完整 LessonResponse 对象 |

## 9. 错题本与练习推荐

### `notebook_items`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `note_` 前缀 |
| `user_id` | string | 归属登录用户；匿名开发模式为 `anonymous` |
| `problem` | string | 题面，不含原图 |
| `topic` | enum | `equation` / `factor` / `function` / `geometry` / `coordinate` / `general` |
| `helpful` | boolean | `false` 表示没听懂，进入错题本待复习 |
| `note` | string | 可选备注，最多 500 字 |
| `stage` | string | 反馈时的课堂阶段 |
| `final_answer` | string | 可选，上次解析答案 |
| `reply` | string | 可选，上次讲解摘要 |
| `created_at` | datetime | 最近一次反馈时间；同用户同题面 upsert |

### `notebook_attempts`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `attempt_` 前缀 |
| `notebook_item_id` | string | 关联 `notebook_items.id`，随错题删除 |
| `user_id` | string | 归属登录用户，查询和写入均校验所有者 |
| `attempt_number` | integer | 该错题下第几次实际提交，从 1 开始 |
| `answer` | string | 学生提交的最终答案，最多 500 字符 |
| `correct` | boolean | SymPy 规则化等价判定结果 |
| `hint_level` | integer | 答错后返回的提示层级：1 知识点、2 关键步骤、3 参考答案；答对为 0 |
| `created_at` | datetime | 提交时间 |

### 重练响应对象

| 字段 | 说明 |
| --- | --- |
| `correct` / `attempt` / `item` | 判定结果、本次尝试和错题最新汇总 |
| `hint.level` / `hint.title` / `hint.body` | 本次递进提示 |
| `final_answer` | 仅第 3 次答错后返回；待复习列表不返回 |
| `can_mark_mastered` | 第 3 次答错后允许学生显式标记已理解 |

### 错题汇总扩展

| 字段 | 说明 |
| --- | --- |
| `attempt_count` / `correct_count` | 累计提交次数 / 累计答对次数 |
| `latest_correct` | 最新一次提交是否答对 |
| `consecutive_wrong` | 从最新记录往前连续答错的次数 |

### 练习推荐对象

| 字段 | 说明 |
| --- | --- |
| `id` | 题库编号 |
| `title` | 展示标题（通常为知识点） |
| `problem` | 题面 |
| `topic` / `topic_label` | 知识点代码与中文名 |
| `reason` | 推荐理由 |
