# 比赛演示与真实模型评测

本文覆盖创新应用赛道提交前的四项交付：真实模型端到端复测、HTTPS 演示环境、比赛账号/一键重置，以及 3 分钟演示视频。

## 1. 比赛账号与一键重置

在部署了正式数据库的 Web 主机执行：

```bash
python3 scripts/reset_competition_demo.py \
  --email student@competition.local \
  --secret-file .competition.env
```

Docker 部署时需进入同一个数据库环境执行，例如：

```bash
docker compose exec math-coach \
  python scripts/reset_competition_demo.py \
  --email student@competition.local \
  --secret-file /app/.competition.env
```

密码生成在容器内时，把它复制到执行验证脚本的主机（保持权限 600）：

```bash
docker compose cp math-coach:/app/.competition.env .competition.env
chmod 600 .competition.env
```

部分 WSL/Windows 挂载盘会忽略 `chmod`。脚本会校验权限；若无法设置为仅所有者可读写，会删除生成的密码文件并报错。此时请改用 `MATH_COACH_COMPETITION_PASSWORD` 环境变量，或把 `--secret-file` 指向支持 POSIX 权限的路径。

如演示前有教学会话正在进行，重置后在页面点击「重新开始」或重启 Web 容器；教学会话和题图只存在应用进程内存中。

脚本会：

1. 创建或复用比赛体验学生账号。
2. 重置强密码；未传入 `MATH_COACH_COMPETITION_PASSWORD` 时生成 18 字节随机密码。
3. 将密码写入 `.competition.env`，文件权限为 `600`，不在终端输出。
4. 清空该学生的登录会话、错题本和重练记录。

演示间隙可重复执行。浏览器端点击「重新开始」即可清理当前教学会话、题图、本地摄像头预览和播放中的语音。

## 2. HTTPS 演示环境

摄像头与麦克风只在 HTTPS 或 `localhost` 下可用；公网评委体验必须使用 HTTPS。

### 2.1 部署步骤

1. 准备域名，例如 `math.example.com`，DNS A 记录指向 Web 主机。
2. 复制 `deploy/nginx-https.conf.example` 为 `/etc/nginx/conf.d/math-coach.conf`，替换域名和证书路径。
3. 使用 Certbot 申请证书：

```bash
sudo certbot --nginx -d math.example.com
```

4. 在 `.env` 设置：

```bash
MATH_COACH_ALLOWED_ORIGINS=https://math.example.com
MATH_COACH_COOKIE_SECURE=true
MATH_COACH_ENABLE_HSTS=true
MATH_COACH_TRUST_PROXY_HEADERS=true
```

5. 启动应用：

```bash
docker compose up -d --build
sudo nginx -t && sudo systemctl reload nginx
```

6. 验证公网环境：

```bash
python3 scripts/verify_https_demo.py \
  --url https://math.example.com \
  --email student@competition.local \
  --secret-file .competition.env
```

验证项包括 HTTPS 首页、HSTS、真实模型配置、体验账号登录、示例接口、SSE 讲解，并确认讲解结果来源为 MiniCPM-o 而不是 Mock 降级。

## 3. 真实模型端到端评测

先加载 `.env` 中的 `MINICPM_API_KEY`，确认 `/api/health` 显示 `mode=minicpm`。全量 30 题默认并发为 2：

```bash
set -a; source .env; set +a
python3 scripts/evaluate_real_model.py --limit 30 --concurrency 2
```

快速冒烟：

```bash
python3 - <<'PY'
from PIL import Image, ImageDraw
image = Image.new('RGB', (900, 300), 'white')
draw = ImageDraw.Draw(image)
draw.text((70, 110), '解方程：2x + 5 = 17。', fill='black')
image.save('/tmp/math-problem.png')
PY
python3 scripts/evaluate_real_model.py \
  --limit 3 --concurrency 1 --image /tmp/math-problem.png
```

报告输出到 `eval/results/real-model-*.json`，包含：

- 提示阶段不泄露答案比例
- 完整答案等价正确率
- 首 token / 首事件延迟
- 完整响应 p50 / p95
- 请求错误数
- 文本、图片识题、TTS 多模态探测
- 每题模型输出和错误原因

评测结果包含模型输出，不包含 API Key。提交前应保留至少一份 30 题完整报告，并在 README 或路演材料中摘录核心指标。

当前已完成的基线见 `../eval/REAL_MODEL_EVALUATION.md`：

- 请求错误：0/30
- 提示护栏：30/30
- 保守答案等价判定：24/30；人工复核格式差异后语义正确 30/30
- 完整解析延迟 p50/p95：17.60s / 77.50s
- 首事件延迟 p50/p95：0.88s / 16.97s
- 文本问答、图片识题、TTS 均通过

## 4. 3 分钟演示视频脚本

建议分辨率 1920x1080、帧率 30fps、浏览器全屏录制、关闭无关标签页。全程使用 `MiniCPM-o Real Mode`。

| 时间 | 画面 | 口播 |
| --- | --- | --- |
| 00:00-00:15 | 首页与 Real Mode 标识 | 这不是普通聊天 Demo，而是面向初中数学的 MiniCPM-o 多模态学习伴侣。 |
| 00:15-00:40 | 登录比赛体验账号 | 学生登录后进入错题本优先视角，系统先看见薄弱知识点。 |
| 00:40-01:20 | 打开摄像头拍题，展示识别和标注 | 学生可以直接拍摄试卷或草稿纸；模型识别题面后允许人工确认和修改。 |
| 01:20-01:50 | 点击确认，输入或说出一步尝试 | 关键点是原图不会丢：确认后的提示和讲解继续携带题图，几何信息仍参与推理；学生必须先尝试一步。 |
| 01:50-02:15 | 点击总结方法，按住说话追问，播放并打断 TTS | 学生完成尝试后获得完整方法总结；老师语音回答可以随时打断，保持自然节奏。 |
| 02:15-02:40 | 标记没听懂，进入错题本，提交重练答案 | 没听懂会沉淀为错题；系统用答案等价判定和递进提示形成学习闭环。 |
| 02:40-03:00 | 展示评测报告和 HTTPS Demo 地址 | 我们用固定题集评测真实模型正确率和延迟，并部署在 HTTPS 环境供评委体验。 |

### 录制注意事项

1. 先执行重置脚本，保证错题本和课堂状态干净。
2. 使用真实 MiniCPM-o，而不是 Mock。
3. 摄像头可以先排练一次，保证题目文字清晰。
4. TTS 打断前稍作停顿，让评委听到语音已开始。
5. 结尾保留 `/api/health` 或页面 Real Mode 标识至少 3 秒。
6. 不要录制 `.competition.env`、管理员密码或浏览器密码管理器。
