# 接口设计

## 1. 通用约定

- 基础地址：`http://127.0.0.1:8080`（FastAPI 一体托管）或映射后的 Docker 地址。
- 前端开发地址：`http://127.0.0.1:3000`（Vite，`/api` 代理到 8080）。
- 请求和普通响应使用 `application/json`；识题上传使用 `multipart/form-data`。
- SSE 使用 `POST /api/lesson/stream`，响应类型为 `text/event-stream`。
- 浏览器受保护接口默认自动携带 HttpOnly Cookie：

```http
Cookie: math_coach_token=<session-token>
```

- 自动化测试也兼容 `Authorization: Bearer <token>`；普通登录/注册响应不再返回 token。
- JSON 错误由 FastAPI 返回 4xx；业务错误信息通常在 `detail` 字段。
- 模型运行时错误在业务响应中转为可读消息；前端收到 401 时清理过渡期缓存并回到登录页。
- `/docs`、`/redoc`、`/openapi.json` 默认关闭；仅在可信环境显式设置 `MATH_COACH_ENABLE_DOCS=true` 后可用。

## 2. 健康与配置

### `GET /api/health`

响应：

```json
{
  "ok": true,
  "mode": "mock",
  "upstream_configured": false,
  "auth_required": true,
  "db_backend": "sqlite"
}
```

### `GET /api/config`

公开接口。返回：

- `mode` / `model` / `provider` / `mvp_mode`
- `auth_required`
- `roles`
- `grades`
- `subjects`（九个学科代码、名称和教学侧重点）
- `demo_accounts`（仅邮箱与标签，不含密码）

`gateway_url` 是兼容字段，固定为空字符串；该接口不向前端暴露上游地址。实际地址来自 `config/minicpm.json` 及可选环境覆盖。

### `GET /api/examples`

**需登录（默认）**。返回示例题数组，每项含 `title`、`problem`、`tag`、`level` 等。

## 3. 认证与个人资料

### `POST /api/auth/register`

公开注册学生/教师。

请求：

```json
{
  "email": "new.student@example.com",
  "password": "Passw0rd1",
  "nickname": "新同学",
  "role": "student",
  "grade": "grade8"
}
```

成功返回 `{"cookie_auth":true,"user":{...}}`，并通过 `Set-Cookie` 下发 HttpOnly 会话 Cookie。
禁止 `role=admin`；密码需 8-128 且含字母数字。

### `POST /api/auth/login`

请求：

```json
{"email":"admin@example.com","password":"<ADMIN_PASSWORD>"}
```

成功返回 `cookie_auth` 与 `public_user`，不返回 token。邮箱/密码错误或账号禁用返回 401。

### `GET /api/auth/me`

需登录。返回当前用户。

### `POST /api/auth/logout`

删除当前 Cookie/Bearer 对应登录会话并清除 Cookie，返回 `{"ok": true}`。

### `PATCH /api/me/profile`

需登录。可更新 `nickname`、学生 `grade`。

## 4. 管理员接口

均需管理员角色，否则 403。

### `GET /api/admin/stats`

返回用户总量、角色分布、会话数、当前推理模式等。

### `GET /api/admin/users`

查询参数：

| 参数 | 说明 |
| --- | --- |
| `role` | 可选，按角色过滤 |
| `status` | 可选，`active` / `disabled` |
| `q` | 可选，邮箱/昵称模糊搜索 |
| `page` | 默认 1 |
| `limit` | 默认 50，最大 200 |

返回 `public_user[]`。

### `PATCH /api/admin/users/{user_id}`

请求体可含 `role` / `status` / `nickname` / `password`。  
约束：不能禁用或降级当前登录管理员自己。

## 5. 题面识别

### `POST /api/recognize`

**需登录（默认）**。`multipart/form-data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `file` | file | 可选；PNG/JPEG/WebP/PDF，最大 8 MB；图片宽高 1-10000 且总像素不超过 20,000,000；PDF 1-20 页、页面宽高不超过 10000，服务端渲染各页为 PNG |
| `problem_text` | string | 可选；文本题面或识别回退 |
| `subject` | string | 可选；当前学科代码，缺省为 `math` |

返回 `RecognizeResponse`，其中 `problems` 为候选题列表、`selected_problem_id` 为默认选题。上传图片和 PDF 页会统一按比例压缩到最长边 1280、JPEG 质量 90，可用 `MINICPM_VISION_MAX_EDGE` / `MINICPM_VISION_JPEG_QUALITY` 调整；高页整页识别只得到一题时，会再用带重叠的上/下分块识别并合并去重，分块标注坐标会还原到原图坐标系。多页 PDF 会逐页调用 MiniCPM-o，识题读超时默认 180 秒，可用 `MINICPM_READ_TIMEOUT_SECONDS` 调整为 10-600 秒。上传为空返回 400，超限返回 413；声明 MIME、文件签名、Pillow 实际格式不一致、PDF 页数/页面非法或尺寸非法返回 415。识别成功但没有完整题目时返回 200、`no_problems=true` 和重拍/手输提示，不创建题图会话。真实模型失败且没有 `problem_text` 时返回 502 和明确错误，不再回退默认例题；提供 `problem_text` 时才显式降级并返回 `degraded=true`、`degraded_reason` 和携带题图的 `session_id`。前端 PDF 预览使用本地 Blob URL，CSP `frame-src 'self' blob:`。摄像头拍题在浏览器端生成 JPEG 文件后走同一接口，不额外引入媒体上传 API。

## 6. 讲解

### `POST /api/lesson`

**需登录（默认）**。请求体：

`tts` 默认为 `false`，普通与流式讲解优先返回文字，不再等待语音生成。旧客户端仍可显式传 `tts=true` 请求文本与音频一起生成。

```json
{
  "session_id": null,
  "problem": "解方程：2x + 5 = 17。",
  "message": "给我一个提示",
  "stage": "hint",
  "tts": false,
  "audio_base64": null,
  "audio_sample_rate": 16000
}
```

返回 `LessonResponse`，其中 `stage` 与请求阶段一致。`stage=hint` 时 `final_answer` 为空；`stage=explain` 时允许填充最终答案，并要求模型额外归纳这类题的可迁移方法。前端在学生完成一次文字或语音尝试后才开放“总结方法”入口。

若 `session_id` 来源于图片识别，学生可在确认前编辑 `problem`；服务端保留该会话中的原图并随本次讲解发送给真实模型。原图只存在内存教学会话，30 分钟未活动或删除会话后不可再访问。

### `POST /api/lesson/stream`

**需登录（默认）**。请求体与 `/api/lesson` 相同。事件顺序：

1. `session`
2. 一个或多个 `text_delta`
3. `lesson`
4. `done`

`audio_base64` 必须是严格 Base64 的 Float32 PCM，字段最长 4,000,000 字符，解码后不超过 60 秒；`audio_sample_rate` 允许 8000-48000。非法音频不发送上游并返回错误。

事件示例：

```text
data: {"type":"session","session_id":"abc"}

data: {"type":"text_delta","text_delta":"先观察等式两边..."}

data: {"type":"lesson","lesson":{"session_id":"abc","reply":"...","steps":[],"final_answer":null,"next_question":"...","confidence":0.97,"source":"mock","audio_base64":null,"audio_mime":null}}

data: {"type":"done"}
```

### `POST /api/speech`

**需登录（默认）**。为已经生成的讲解文本按需生成语音，不读取或修改教学会话，也不重复发送题图。

```json
{
  "subject": "math",
  "text": "先观察等式两边，再考虑使用逆运算。"
}
```

成功返回 `audio_base64`、`audio_mime` 和 `source=minicpm`。Mock 模式返回 503，前端自动回退浏览器语音合成；上游异常或没有音频时返回 502。

## 7. 会话删除与反馈

### `DELETE /api/session/{session_id}`

**需登录（默认）**。删除当前用户拥有的后端课堂会话，返回：

```json
{"deleted": true}
```

不存在或不属于当前用户的 ID 均返回 `{"deleted": false}`，不泄露会话是否存在。前端在确认题面前移除图片会调用该接口清掉题图上下文；确认后隐藏预览不会调用该接口，因为后续讲解仍需题图。

### `POST /api/feedback`

**需登录（默认）**。请求体：`{"problem":"...","helpful":false,"note":"...","session_id":"...","stage":"explain"}`。
按用户 + 题面 upsert 到错题本；`helpful=false` 记为待复习。不保存原始图片和音频。

### `GET /api/notebook`

**需登录（默认）**。查询参数：`filter=all|wrong|mastered`、`topic`、`limit`。
返回 `{ items, stats }`，`stats` 含 `total` / `wrong` / `mastered`。

### `DELETE /api/notebook/{item_id}`

**需登录（默认）**。只能删除当前用户自己的条目，返回 `{"deleted": true|false}`。

### `POST /api/notebook/{item_id}/attempts`

**需登录（默认）**。请求体：`{"answer":"x = 6"}`。
服务端使用 SymPy 规则化等价判断答案；每次提交写入 `notebook_attempts`。答错分别按第 1/2/3 次返回知识点、关键步骤和参考答案；答对一次即把错题标记为掌握。待复习列表不返回 `final_answer`。

### `GET /api/notebook/{item_id}/attempts`

**需登录（默认）**。返回当前用户该错题的作答历史，按提交时间倒序；支持 `limit`（1-100）、`offset` 和 `pagination.total` 分页，可翻页取得完整历史。

### `POST /api/notebook/{item_id}/mastered`

**需登录（默认）**。第 3 次答错并展示参考答案后，学生可显式标记“看懂了”；不虚构一次作答记录。

### `POST /api/practice/recommend`

**需登录（默认）**。请求体：`{"problem":"...","topic":"equation","limit":3,"exclude":[]}`。
按题型返回最多 8 道同类练习；未传题面时优先使用该用户错题本薄弱知识点。

## 8. HTTP 状态与处理建议

| 状态 | 含义 | 前端处理 |
| --- | --- | --- |
| 200 | 正常响应或 SSE 建立成功 | 更新页面 |
| 400/422 | 请求字段或上传文件不合法 | 显示错误并允许修正 |
| 401 | 未登录、会话失效或账号禁用 | 清理会话，回到登录页 |
| 403 | 已登录但角色不足 | Toast 提示无权限 |
| 404 | 静态资源、未知路径或已关闭的文档接口 | 检查部署地址 |
| 413 | 上传图片/PDF 超过 8 MB | 提示压缩后重传 |
| 415 | 图片 MIME/内容/尺寸校验失败 | 提示更换合法图片 |
| 429 | 登录/注册或通用 API 限流 | 提示稍后重试 |
| 500 | 未预期服务错误 | Toast 提示并查看服务日志 |

## 9. 冒烟示例

```bash
# 登录并保存 HttpOnly Cookie
curl -s -c /tmp/math-coach.cookies -X POST http://127.0.0.1:8080/api/auth/login   -H 'content-type: application/json'   -d '{"email":"admin@example.com","password":"<ADMIN_PASSWORD>"}'

# 受保护讲解流
curl -N -b /tmp/math-coach.cookies -X POST http://127.0.0.1:8080/api/lesson/stream   -H 'content-type: application/json'   -d '{"problem":"矩形长 6，宽 4，求面积。","message":"给我一个提示","stage":"hint","tts":false}'
```
