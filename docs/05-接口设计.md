# 接口设计

## 1. 通用约定

- 基础地址：`http://127.0.0.1:8080`（FastAPI 一体托管）或映射后的 Docker 地址。
- 前端开发地址：`http://127.0.0.1:3000`（Vite，`/api` 代理到 8080）。
- 请求和普通响应使用 `application/json`；识题上传使用 `multipart/form-data`。
- SSE 使用 `POST /api/lesson/stream`，响应类型为 `text/event-stream`。
- 受保护接口需要请求头：

```http
Authorization: Bearer <token>
```

- JSON 错误由 FastAPI 返回 4xx；业务错误信息通常在 `detail` 字段。
- 模型运行时错误在业务响应中转为可读消息；前端收到 401 时清理 token 并回到登录页。

## 2. 健康与配置

### `GET /api/health`

响应：

```json
{
  "ok": true,
  "mode": "mock",
  "upstream_configured": false,
  "auth_required": true,
  "db_backend": "sqlite"
}
```

### `GET /api/config`

公开接口。返回：

- `mode` / `model` / `gateway_url` / `provider` / `mvp_mode`
- `auth_required`
- `roles`
- `grades`
- `demo_accounts`（仅邮箱与标签，不含密码）

`gateway_url` 兼容字段，实际值来自 `VLLM_OMNI_URL`（优先）或旧的 `MINICPM_GATEWAY_URL`。

### `GET /api/examples`

**需登录（默认）**。返回示例题数组，每项含 `title`、`problem`、`tag`、`level` 等。

## 3. 认证与个人资料

### `POST /api/auth/register`

公开注册学生/教师。

请求：

```json
{
  "email": "new.student@example.com",
  "password": "Passw0rd1",
  "nickname": "新同学",
  "role": "student",
  "grade": "grade8"
}
```

成功返回 `{"token":"...","user":{...}}`。  
禁止 `role=admin`；密码需 8-128 且含字母数字。

### `POST /api/auth/login`

请求：

```json
{"email":"teacher@demo.local","password":"demo123"}
```

成功返回 token 与 `public_user`。邮箱/密码错误或账号禁用返回 401。

### `GET /api/auth/me`

需登录。返回当前用户。

### `POST /api/auth/logout`

删除当前 Bearer 对应登录会话，返回 `{"ok": true}`。

### `PATCH /api/me/profile`

需登录。可更新 `nickname`、学生 `grade`。

## 4. 管理员接口

均需管理员角色，否则 403。

### `GET /api/admin/stats`

返回用户总量、角色分布、会话数、当前推理模式等。

### `GET /api/admin/users`

查询参数：

| 参数 | 说明 |
| --- | --- |
| `role` | 可选，按角色过滤 |
| `status` | 可选，`active` / `disabled` |
| `q` | 可选，邮箱/昵称模糊搜索 |
| `page` | 默认 1 |
| `limit` | 默认 50，最大 200 |

返回 `public_user[]`。

### `PATCH /api/admin/users/{user_id}`

请求体可含 `role` / `status` / `nickname` / `password`。  
约束：不能禁用或降级当前登录管理员自己。

## 5. 题面识别

### `POST /api/recognize`

**需登录（默认）**。`multipart/form-data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `file` | file | 可选；PNG/JPEG/WebP，最大 8 MB |
| `problem_text` | string | 可选；文本题面或识别回退 |

返回 `RecognizeResponse`。

## 6. 讲解

### `POST /api/lesson`

**需登录（默认）**。请求体：

```json
{
  "session_id": null,
  "problem": "解方程：2x + 5 = 17。",
  "message": "给我一个提示",
  "stage": "hint",
  "tts": true,
  "audio_base64": null,
  "audio_sample_rate": 16000
}
```

返回 `LessonResponse`。`stage=hint` 时 `final_answer` 为空；`stage=explain` 时允许填充最终答案。

### `POST /api/lesson/stream`

**需登录（默认）**。请求体与 `/api/lesson` 相同。事件顺序：

1. `session`
2. 一个或多个 `text_delta`
3. `lesson`
4. `done`

事件示例：

```text
data: {"type":"session","session_id":"abc"}

data: {"type":"text_delta","text_delta":"先观察等式两边..."}

data: {"type":"lesson","lesson":{"session_id":"abc","reply":"...","steps":[],"final_answer":null,"next_question":"...","confidence":0.97,"source":"mock","audio_base64":null,"audio_mime":null}}

data: {"type":"done"}
```

## 7. 会话删除与反馈

### `DELETE /api/session/{session_id}`

**需登录（默认）**。删除后端课堂会话，返回：

```json
{"deleted": true}
```

不存在的 ID 返回 `{"deleted": false}`。

### `POST /api/feedback`

**需登录（默认）**。请求体：`{"problem":"...","helpful":true,"note":"..."}`。  
MVP 返回接受结果，不保存原始图片和音频。

## 8. HTTP 状态与处理建议

| 状态 | 含义 | 前端处理 |
| --- | --- | --- |
| 200 | 正常响应或 SSE 建立成功 | 更新页面 |
| 400/422 | 请求字段或上传文件不合法 | 显示错误并允许修正 |
| 401 | 未登录、token 失效或账号禁用 | 清理 token，回到登录页 |
| 403 | 已登录但角色不足 | Toast 提示无权限 |
| 404 | 静态资源或未知路径 | 检查部署地址 |
| 500 | 未预期服务错误 | Toast 提示并查看服务日志 |

## 9. 冒烟示例

```bash
# 登录
TOKEN=$(curl -s -X POST http://127.0.0.1:8080/api/auth/login   -H 'content-type: application/json'   -d '{"email":"teacher@demo.local","password":"demo123"}' | python3 -c 'import sys,json; print(json.load(sys.stdin)["token"])')

# 受保护讲解流
curl -N -X POST http://127.0.0.1:8080/api/lesson/stream   -H "authorization: Bearer $TOKEN"   -H 'content-type: application/json'   -d '{"problem":"矩形长 6，宽 4，求面积。","message":"给我一个提示","stage":"hint","tts":false}'
```
